📖 How to Use Side Profile Labeler

Method A: MediaPipe Auto-Detect (Browser)
1. Upload a side profile photo
2. Click "MediaPipe Detect" to run face mesh (478 points)
3. For each custom landmark, select the best matching detected point
4. Or use "Auto-assign" for heuristic-based matching

Method B: PyTorch Face Landmark (39-point profile)
1. Run: python side_detect.py your_photo.jpg
2. This outputs side_detection.json with 39 profile points
3. Upload same photo here, click "Load PT Detection"
4. Select the JSON file → 39 green points appear
5. Map custom landmarks to those 39 points

Method C: Manual Placement
1. Upload a side profile photo
2. Select each landmark and click "Place manually"
3. Click on the image to position the point
